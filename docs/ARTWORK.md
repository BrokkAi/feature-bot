# Feature Bot artwork

`feature-reader.png` is original artwork generated on 2026-09-10 with the built-in
ImageGen tool for Brokk Feature Bot and Brokk Town. It depicts a studious robot
with round reading glasses, a burgundy waistcoat, and an open book. The original
RGBA PNG is preserved without image edits. The exact prompt and tool mode are
recorded in `artwork-prompt.json`. It is distributed under this project's
Apache-2.0 license. No external game sprites were bundled.
